换算口径

每 1% 等价美元 = 期间 API 等价金额 ÷ 已用百分比；整窗估算 = 每 1% 等价美元 × 100。外推沿用本周期的模型与 Fast 使用比例，会随使用情况变化。

各窗口覆盖的调用可能重叠，金额分别查看。金额来自此日志目录的本地调用，无法核对调用所属账号，也不包含其他设备和云端的使用；属于 API 等价估算，不是订阅账单或可购买的额度价格。

未定价调用不计入金额；有已定价调用时，仍用已知金额计算每 1%、整窗和剩余额度，并标为已知金额估算。点击“刷新并换算”会扫描新日志并读取额度；切换页面沿用最近一次额度读数。

每次成功读取额度都会保存当次两种价格口径的换算结果。历史金额不会随后续价格修改重算，源日志清空后仍保留已保存的调用和读数。实时读取失败时显示当前账号的本地历史；账号无法识别时显示上次保存账号的历史，并明确标注为离线记录。尚未采集的旧周期无法补造。
